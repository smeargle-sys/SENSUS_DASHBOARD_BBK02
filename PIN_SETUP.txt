================================================================================
  GANTI PIN (Update)
================================================================================

Jika ingin mengubah PIN:

1. Buka Project Settings → Script Properties (seperti step 1-3 di atas)
2. Cari property yang ingin diubah (misal: ADMIN_PIN)
3. Klik value-nya
4. Edit value dengan PIN baru
5. Klik "Save"
6. Inform semua user tentang PIN baru

Contoh update:
  ADMIN_PIN: A21112026#! → A21112026#! (new)
  VIEWER_PIN: v21112026#? → v21112026#? (new)

================================================================================
  TROUBLESHOOTING
================================================================================

Q: PIN tidak bekerja, padahal sudah set di Script Properties?

A1: Cek spelling PIN - harus exact match (case-sensitive)
A2: Refresh halaman sebelum login ulang (cache issue)
A3: Cek apakah Script Properties sudah tersimpan dengan klik "Save"
A4: Coba deploy ulang sistemnya (New Deployment)

Q: Lupa PIN, bagaimana?

A: Admin bisa lihat di Script Properties → Script Properties
   Jika lupa, bisa diganti dengan PIN baru sesuai langkah "GANTI PIN"

Q: PIN tidak muncul di halaman login?

A: Ini normal - PIN aman disimpan di backend (Script Properties)
   User hanya perlu input PIN, tidak bisa dilihat di halaman
